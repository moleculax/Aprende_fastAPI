## ¿Qué es FastAPI?

**FastAPI** es un framework web moderno y de alto rendimiento para construir APIs con Python 3.8+. Está basado en los estándares **OpenAPI** y **JSON Schema**, lo que permite generar documentación automática e interactiva.

[![FastAPI](https://img.shields.io/badge/FastAPI-005571?style=for-the-badge&logo=fastapi)](https://fastapi.tiangolo.com/)
[![Python](https://img.shields.io/badge/Python-3.8%2B-blue?style=for-the-badge&logo=python&logoColor=white)](https://www.python.org/)
[![OpenAPI](https://img.shields.io/badge/OpenAPI-3.1.0-6BA539?style=for-the-badge&logo=openapiinitiative&logoColor=white)](https://www.openapis.org/)
[![JSON Schema](https://img.shields.io/badge/JSON%20Schema-Draft%2007-6BA539?style=for-the-badge&logo=jsonschema&logoColor=white)](https://json-schema.org/)

### Características principales:

| Característica | Descripción |
|----------------|-------------|
|  **Alto rendimiento** | Equiparable a Node.js y Go gracias a Starlette y Pydantic |
|  **Documentación automática** | Genera Swagger UI y ReDoc de forma nativa |
|  **Seguridad** | Soporte integrado para autenticación OAuth2, JWT y más |
|  **Validación automática** | Basada en tipos de Python con Pydantic |
|  **Rápido de codificar** | Aumenta la velocidad de desarrollo entre 200% y 300% |
|  **Mantenible** | Diseñado con tipado estático y dependencias inyectables |
|  **Compatible** | Soporta bases de datos, WebSockets, GraphQL y más |

##  Descripción

Este repositorio contiene una serie de ejemplos organizados por nivel de dificultad para ayudarte a dominar FastAPI, uno de los frameworks web más rápidos y modernos para Python.

Cada ejemplo está cuidadosamente comentado y diseñado para enseñar un concepto específico, desde la configuración básica hasta técnicas avanzadas.
