# 🚀 FastAPI Learning Examples

Una colección de ejemplos prácticos para aprender FastAPI desde cero hasta niveles avanzados.

## 📋 Descripción

Este repositorio contiene una serie de ejemplos organizados por nivel de dificultad para ayudarte a dominar FastAPI, uno de los frameworks web más rápidos y modernos para Python.

Cada ejemplo está cuidadosamente comentado y diseñado para enseñar un concepto específico, desde la configuración básica hasta técnicas avanzadas.

## 📚 Contenido del Repositorio

**🔰 Nivel Básico** 

**📘 Nivel Intermedio**

**🚀 Nivel Avanzado**

## 🛠️ Tecnologías Utilizadas

- **FastAPI**: Framework web principal
- **Pydantic**: Validación de datos
- **Uvicorn**: Servidor ASGI
- **SQLAlchemy**: ORM para base de datos
- **JWT**: Autenticación
- **Pytest**: Pruebas unitarias

## 📦 Requisitos Previos

- Python 3.8+
- pip (gestor de paquetes)
- Git
